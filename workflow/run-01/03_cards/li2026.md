# 證據卡：li2026

來源頁：`wiki/papers/li2026.md`（多參數 MRI 預測中風預後：梗塞位置＋radiomics＋腦部衰弱度）

- **C1**〔研究設計〕回溯性研究，5 家中心共 1051 位前循環大血管阻塞 (LVO) 病人 [li2026, p.1]。
- **C2**〔研究設計〕其中 4 家中心分成訓練（n = 612）與內部驗證（n = 263），第 5 家中心的 176 人做外部驗證 [li2026, p.1]。
- **C3**〔研究設計〕腦部衰弱度 (brain frailty) 用腦萎縮、白質高訊號 (WMH)、舊梗塞評估 [li2026, p.1]。
- **C4**〔模型與結果〕外部驗證 AUC = 0.86（95% CI：0.80–0.91）[review, §3.2]。
- **C5**〔模型與結果〕內部驗證到外部驗證：0.84 → 0.86 [review, §4.3]。
- **C6**〔模型與結果〕另外做了 decision-curve analysis 與 calibration curve [li2026, p.6]。
- **C7**〔XAI 怎麼做〕SHAP 平均絕對值最高的特徵：lentiform nucleus 病灶負荷、WMH、M6 區病灶負荷 [li2026, p.2]。
- **C8**〔Review 的評論〕Review 選為正文詳述的研究之一 [review, §3]。
- **C9**〔Review 的評論〕偏誤風險：Unclear。原因是沒交代流程隔離 (pipeline isolation)，而不是確認有資料外洩 [review, §5.4]。
- **C10**〔Review 的評論〕多中心影像用標準化前處理 [review, §4.3]。
